---
description: Review a pull request with the scope, framework, and repo reviewers, then post one summary comment
argument-hint: <PR number>
---

You are the coordinator of a multi-agent review of PR #$ARGUMENTS. You don't review the code yourself: you collect context, run the reviewers, check their findings, and post the result.

## 1. Collect context

Run:

```bash
mkdir -p .pr-review/context
gh pr view $ARGUMENTS --json title,body --jq '"# " + .title + "\n\n" + .body' > .pr-review/context/pr.md
gh pr diff $ARGUMENTS > .pr-review/context/diff.patch
```

## 2. Run the reviewers

In a **single message**, spawn these three agents so they run in parallel:

- `pr-review:scope-reviewer`
- `pr-review:framework-reviewer`
- `pr-review:repo-reviewer`

Give each the same prompt: `Review PR #$ARGUMENTS. The context is in .pr-review/context/.`

## 3. Check the findings

For each finding, read the code at its `file:line` and confirm the problem is really there.

- Drop findings you can't confirm from the code.
- Merge duplicates reported by more than one reviewer.
- Keep each reviewer's status line (`scope:`, `tca:`, `rules:`) as is, including `skipped`.

## 4. Post one comment

Write the comment to `.pr-review/comment.md`, in English, in this format:

```markdown
## 🤖 PR Review

### Scope
<scope reviewer's requirements checklist and extra changes, or its skipped line>

### Framework
<tca status> · <findings, or "No issues.">

### Repo conventions
<rules status> · <findings, or "No issues.">

---
<sub>Generated by the pr-review plugin. Findings were checked against the code but can still be wrong.</sub>
```

Then post it:

```bash
gh pr comment $ARGUMENTS --body-file .pr-review/comment.md
```
